# icosahedrality-analysis
Code used in "ReaxFF Parameter Set for Boron Clusters and Icosahedral Boron Crystals: Comparison with Density Functional Theory and Machine-Learning Potentials", 2025, to compute icosahedrality from MD trajectories (PDB/DCD) using MDTraj.

An OVITO modifier version of the same analysis is in [`ovito/`](ovito/README.md).
